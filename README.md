# abcgoundas

Small HTML and Node/Express practice projects.

## Files

- `lcm-calculator.html` - browser-only LCM calculator.
- `lcm-calculator-apex.html` - Apex copy of the LCM calculator UI.
- `hcf-calculator.html` - browser-only HCF calculator.
- `solar-system-animation.html` - CSS solar system animation.
- `timer.html` - browser timer demo.
- `lcm-ejs-server.js` - Express/EJS LCM calculator.
- `lcm-query-server.js` - Express LCM calculator using query params.

## Run

```bash
npm install
npm start
```
